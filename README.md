[ F L I C K P A D ]


**What is *FlickPad*?**

Use your gamepad to input text, use macros, and control the cursor. Forget mouse and keyboard!

Customize your layouts, adjust your settings, and save it all to a profile, then just press your shortcut and immediately start typing.

**How it works:**

The keyboard layout is similar to MessagEase/ThumbKey/FlickBoard. 
The left thumbstick chooses the zone from a 3x3 grid (8 directions + neutral), the right thumbstick chooses the character within it (8 directions). 
Simply letting go of the right thumbstick inputs the chosen character.
How can you remember 72 (9 x 8) custom character positions? Well you don't have to! Optionally enable a floating keyboard overlay to show you the layout and auto-hide when unnecessary. 

Map all the other buttons on your gamepad to an action of your choice (space, delete, undo, copy, cycle layouts, volume control, etc.) to do whatever is intuitive.
Also create button combination shortcuts for less used actions with up to 4 simultaneous buttons. 

Press the Cursor Mode shortcut to control the on-screen cursor using the thumbsticks. 
Use either both thumbsticks at the same time to move and zoom with the cursor, or map one of them to cursor movement and the other to zoom/scroll/pan/other actions. 
Of course, all the other gamepad buttons are available for mapping mouse clicks and actions to whatever is intuitive. 

**What can I adjust?**

Within a single profile you can adjust:

16 custom layouts (with multi-character, symbol and emoji inputs)
Every face button, trigger, and bumper mapping to an action/command of your choice
Near-unlimited button combination chains for custom actions, functions, or macros. 
Cursor sensitivity and acceleration adjustments.
Cursor mode-specific button and button combination mappings, thumbstick action assignments.
Mode toggle shortcuts, floating keyboard overlay settings. 
Individual thumbstick deadzones.

And of course, you can save, import and export profiles in JSON format as much as you like!
